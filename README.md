# Lumen Fault

Lumen Fault is a classic browser-based arcade game built with HTML, CSS, and JavaScript. It blends retro-inspired gameplay with a neon survival loop, where you manage aura, collect gear, survive enemies, and progress through increasingly challenging levels.

## Overview

This project is a single-file game experience with:

- a grid-based exploration system
- survival mechanics and aura management
- day/night cycle transitions
- inventory and item pickups
- enemy encounters and combat
- a polished retro UI and arcade-style presentation

The main game file is:

- `Lumen trail ver1.2.html`

## How to Play

1. Clone or download this repository.
2. Open `Lumen trail ver1.2.html` in your browser.
3. Press the space bar to begin.
4. Use the keyboard controls below to explore and survive.

## Controls

- Arrow Keys: Move
- Space: Interact / Attack
- E: Open inventory
- R: Restart level
- ~: Open admin/debug panel

## Gameplay Goals

- Manage your aura to avoid losing the run.
- Gather useful items such as weapons, shields, lamps, and other tools.
- Survive enemy attacks and the shifting day/night cycle.
- Clear grave threats and complete each level objective.
